# Deployment (free tiers)

MongoDB Atlas (database), Render (API + Socket.io), Vercel (React app).
Redis is switched off (`DISABLE_REDIS=true`): cache, queue and socket adapter degrade gracefully on one instance.

Config in the repo: `render.yaml` (API blueprint), `frontend/vercel.json` (SPA rewrites), `backend/.env.example`, `frontend/.env.example`.

## 1. MongoDB Atlas
1. cloud.mongodb.com → create a free **M0** cluster.
2. Database Access → add user (password auth). Save username + password.
3. Network Access → Add IP → `0.0.0.0/0` (Render free has no fixed IP; access is still password protected).
4. Connect → Drivers → copy the URI, insert the password and a DB name:
   `mongodb+srv://USER:PASS@cluster0.xxxxx.mongodb.net/sustainable_db?retryWrites=true&w=majority`

## 2. Render (API)
1. Push the branch to GitHub.
2. render.com → New → **Blueprint** → pick the repo. It reads `render.yaml`.
3. Fill the variables it asks for:
   | Key | Value |
   |-----|-------|
   | MONGO_URI | Atlas URI from step 1 |
   | CLIENT_URL | Vercel URL from step 3 (put a placeholder now, update after) |
   | RAZORPAY_KEY_ID / RAZORPAY_KEY_SECRET | Razorpay **test** keys (`rzp_test_...`). Required: sandbox `mock_` payments are disabled in production |
   | CLOUDINARY_* | optional; without them sellers paste image URLs |
   `JWT_SECRET` is generated by Render automatically.
4. Deploy. Check `https://<service>.onrender.com/` returns 200.
5. Optional demo data (**wipes the target DB**), from your machine:
   `cd backend && MONGO_URI="<atlas uri>" node src/scripts/seed.js`

## 3. Vercel (frontend)
1. vercel.com → Add New → Project → import the repo.
2. Root Directory: `frontend`. Framework: Vite (build `npm run build`, output `dist`).
3. Environment variables:
   | Key | Value |
   |-----|-------|
   | VITE_API_BASE_URL | `https://<service>.onrender.com/api` |
   | VITE_SOCKET_URL | `https://<service>.onrender.com` |
   | VITE_RAZORPAY_KEY_ID | same `rzp_test_...` key id |
4. Deploy, copy the URL (e.g. `https://sustainable-xyz.vercel.app`).
5. Back in Render → Environment → set `CLIENT_URL` to that URL (no trailing slash; comma-separate several) → save (redeploys).

## 4. Smoke test
- Open the Vercel URL, register a buyer, browse, open a product.
- Log in as a seller in another browser, list a product; approve it as admin; buy it as buyer with Razorpay test card.
- Open an auction in two browsers and bid: the other window updates live.

## Known limits of the free plan
- Render free sleeps after ~15 min idle; first request takes ~30–60 s. While asleep, the auction sweeper doesn't run; it closes overdue auctions on wake, and late bids are still rejected because `placeBid` checks the end time atomically.
- One API instance and no Redis, so Socket.io rooms are in memory (fine for one instance).
- Never commit `.env`; secrets live only in the Render and Vercel dashboards.
